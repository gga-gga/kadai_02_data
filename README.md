# MMA Fighter Data Analysis
## データが語る「勝利の法則」― UFC選手スタッツの収集と回帰分析

### 収集方法の実装と、実際に発生した問題

`ufc_scraper.py` は UFCStats.com を `requests` + `BeautifulSoup4` で
スクレイピングする想定で実装し、実際に8選手分の取得に成功しています
（`ufc_sample_data.csv` がその実データです）。

しかし、本分析のために中規模サンプル（500〜800人）を新規取得しようとした際、
UFCStats.com側でBot対策（JavaScriptによるブラウザ確認チャレンジ）が
作動し、`requests`ベースのアクセスがブロックされる事態が発生しました
（おそらく事前の全件カウント調査でリクエスト数が増えたことが一因）。

このため、本分析では **UFCStats.com を一次ソースとして同一データを
収集・公開している既存のオープンデータ**（GitHub:
[sagi778/UFC-Data-Extractor](https://github.com/sagi778/UFC-Data-Extractor)、
`data/ufc_fighters_stats.csv`、4,039選手分）を取得し、`prepare_dataset.py`
で本プロジェクトのスキーマに変換して分析に使用しました。
データの出自（UFCStats.com由来）・カラム構成は自作スクレイパーの設計と同一です。

> **Note:** ESPN MMA FightCenterはJavaScriptレンダリングのため
> `requests`では取得不可と判明し、当初からUFCStats.com系のデータに統一しています。
> UFCStats.com はHTTPのみ対応のサイトです（HTTPS非対応）。

## データの仕様（ufc_analysis_data.csv）

height_cm・reach_cmが欠損している選手を除外した **2,053 選手分**のデータです。

### カラム一覧

| カラム名 | 内容 | 単位 |
|----------|------|------|
| `name` | 選手名 | — |
| `weight_class` | 体重クラス（自動分類） | — |
| `height_cm` | 身長 | cm |
| `weight_lbs` | 体重 | lbs |
| `reach_cm` | リーチ | cm |
| `stance` | スタンス（Orthodox / Southpaw / Switch） | — |
| `dob` | 生年月日 | — |
| `wins` / `losses` / `draws` | 勝敗数 | 回 |
| `win_rate` | 勝率 | % |
| `slpm` | 打撃ヒット数（Sig. Strikes Landed/Min） | 回/分 |
| `str_acc` | 打撃命中率 | % |
| `sapm` | 被弾数（Sig. Strikes Absorbed/Min） | 回/分 |
| `str_def` | 打撃回避率 | % |
| `td_avg` / `td_acc` / `td_def` / `sub_avg` | 組技関連スタッツ | — |
| `ape_index` | **エイプ・インデックス**（リーチ÷身長） | 比率 |
| `url` | 取得元URL | — |

```
ape_index = reach_cm ÷ height_cm
```
1.00超 = リーチが身長を上回る（打撃レンジに優位性あり）。
身長に対するリーチの比率を見ることで、異なる階級の選手を公平に比較できる。

## 検証した仮説と分析結果

### 仮説①　防御力が勝率を決める

高勝率選手は「打撃命中率（攻撃）」よりも「打撃回避率・被弾数（防御）」に
共通点があるのではないか。→ **Pearson相関係数** で検証。

#### 結果（n=2,050、3戦以上）

| 指標 | 分類 | r | p値 | 意味 |
|------|------|---|------|------|
| str_acc（打撃命中率） | 攻撃 | +0.098 | <0.001 | 高いほど勝率も高い傾向 |
| slpm（打撃量/分） | 攻撃 | +0.116 | <0.001 | 高いほど勝率も高い傾向 |
| str_def（打撃回避率） | 防御 | -0.086 | <0.001 | **高いほど勝率は低い傾向（直感に反する）** |
| sapm（被弾数/分） | 防御 | -0.130 | <0.001 | 高いほど（多く被弾するほど）勝率は低い傾向 |

![攻撃vs防御の相関](hypothesis1_offense_vs_defense.png)

**結論：仮説①は単純には支持されない。** すべての指標がp<0.001で統計的には
有意だが、いずれも|r|は0.1前後と非常に弱い相関にすぎない。さらに、相関の
絶対値としては防御指標（sapm: -0.130）が攻撃指標（slpm: +0.116）をわずかに
上回るため「防御の方が影響力が大きい」という方向性自体は支持されるが、
**str_def（打撃回避率）が勝率と負の相関を示す**という直感に反する結果が出た。

これは、防御重視・カウンター待ちのスタイルの選手は被弾を避けて回避率は
高くなる一方、判定に持ち込まれやすく実際の勝率は伸びにくい、といった
スタイル上のトレードオフが影響している可能性がある。Sig. Strikes Absorbed
（sapm）の方が勝率との関係が一貫しており、「回避率（%）」という相対指標より
「被弾の絶対量」の方が勝敗に直結しやすいことを示唆している。

再現するには:
```bash
python analyze_hypothesis1.py --input ufc_analysis_data.csv
```

### 仮説③　エイプ・インデックスが被弾率を下げる

単純なリーチの長さではなく、身長に対するリーチの比率（ape_index）が
被弾率の低さ（str_defの高さ / sapmの低さ）と相関するのではないか。
→ **単回帰分析（線形回帰）** で検証。

#### 結果（n=2,050、3戦以上の選手）

| 回帰 | 係数(slope) | r | R² | p値 | 判定 |
|------|------------|---|----|-----|------|
| ape_index → str_def | -5.86 | -0.013 | 0.0002 | 0.549 | 有意でない |
| ape_index → sapm | -2.29 | -0.037 | 0.0014 | 0.096 | 有意でない |

**結論：仮説③は支持されない。** 2,000人超の大規模サンプルでも、
エイプ・インデックス単体では打撃の被弾しやすさを統計的に説明できなかった。

#### 頑健性チェック（階級別）

9階級すべてで個別に相関を確認したが、いずれも |r| < 0.11、p > 0.3 で
有意な関係は見られず、階級による交絡が結果を隠していたわけではないことを確認した。

#### 参考：勝率との関係

ape_index と win_rate（勝率）の相関は r=0.062, p=0.005 と統計的には有意
だったが、相関は極めて弱く、サンプルサイズの大きさによる「統計的有意性」
であり実務的な効果量はごく小さいと考えられる。

#### 考察

リーチ／身長比という分かりやすい身体的指標だけでは、防御力や勝率の
差を説明するには不十分であることが示された。打撃回避率は技術・反応速度・
スタンスなど、身体的指標以外の要因に強く依存している可能性が高い。
「リーチが長い選手は打たれにくい」という直感的な仮説は、データ上では
裏付けられなかった点が本分析の発見である。

再現するには:
```bash
pip install pandas scipy matplotlib
python prepare_dataset.py          # alt_fighters_stats.csv → ufc_analysis_data.csv
python analyze_hypothesis3.py --input ufc_analysis_data.csv
```

### 仮説②　階級によってサウスポーの有利性は変わる

軽量級ほどサウスポーの角度優位が高く、重量級ではKO力がその恩恵を相殺する
「構造的差異」があるのではないか。→ **カイ二乗検定** で検証。

#### 方法

各階級ごとに、スタンス（Southpaw / Orthodox）× 勝率階層（その階級内の中央値で
High/Lowに分割）の2×2分割表を作成し、カイ二乗検定で独立性を検定。
試合データ（対戦カード）がない選手単位の集計データのため、直接対戦結果は使えず、
「サウスポー選手がOrthodox選手より高勝率グループに入りやすいか」という指標で代替。

#### 結果（n=2,050、3戦以上）

| 階級 | n | サウスポー高勝率率 | オーソドックス高勝率率 | χ² | p値 |
|------|---|---------------------|--------------------------|-----|------|
| Strawweight | 87 | 63.6% | 48.7% | 0.365 | 0.546 |
| Flyweight | 194 | 47.9% | 52.1% | 0.110 | 0.741 |
| Bantamweight | 259 | 52.5% | 50.7% | 0.002 | 0.969 |
| Featherweight | 229 | 52.3% | 50.8% | 0.000 | 0.995 |
| Lightweight | 316 | 50.0% | 50.0% | 0.000 | 1.000 |
| Welterweight | 286 | 54.5% | 50.6% | 0.137 | 0.712 |
| Middleweight | 211 | 61.4% | 46.1% | 3.307 | 0.069 |
| Light Heavyweight | 161 | 39.1% | 52.2% | 0.871 | 0.351 |
| Heavyweight | 137 | 63.2% | 48.3% | 0.911 | 0.340 |

![階級別サウスポー比較](hypothesis2_by_weightclass.png)

**結論：仮説②は支持されない。** 全9階級でp値が0.05を上回り、統計的に有意な
スタンスと勝率の関連は確認できなかった（Middleweightがp=0.069で最も近いが
有意水準には届かない）。

軽量級3階級（Straw/Fly/Bantam）の平均ギャップは+4.2pt、重量級2階級
（LightHeavy/Heavy）は+0.9ptで、方向としては「軽量級の方がサウスポー優位が
大きい」という仮説のイメージに近い傾向が見えるが、いずれも統計的有意性はなく、
偶然のばらつきの範囲内と判断するのが妥当である。

再現するには:
```bash
python analyze_hypothesis2.py --input ufc_analysis_data.csv
```

### 仮説④　年齢には「ピーク（全盛期）」があり、勝率と逆U字の関係を持つ

選手は若すぎれば経験不足、年を取りすぎれば身体的な衰えにより勝率が下がり、
中間のどこかに「全盛期（ピーク）」があるのではないか。
→ **二次の重回帰分析（win_rate ~ age + age²）** で検証。

#### 年齢の定義について

選手の「現在の年齢（今日 − 生年月日）」は、引退済み・現役引退状態の選手が
多数含まれる本データセットでは不適切である（現在の年齢は、実際に戦績を
積んだ時期の年齢を反映しない）。そこで、生データ（`alt_fighters_stats.csv`）
に含まれる `last_match`（直近の試合日）と `dob`（生年月日）を `url` キーで
`ufc_analysis_data.csv` に結合し、

```
age_at_last_match = last_matchの年 − dobの年
```

という「直近の試合時点での年齢」を算出し、これを年齢の指標として採用した。
（生年月日の表記が`"Aug26,1994"`のような特殊フォーマットだったため、
`datetime.strptime(..., "%b%d,%Y")` でパースしている。）

#### 結果（n=1,859、3戦以上、年齢16〜50歳でフィルタ）

| 項目 | 係数 | p値 |
|------|------|-----|
| 切片 | 118.26 | <0.001 |
| age（1次項） | -2.361 | <0.001 |
| age²（2次項） | +0.0278 | 0.0023 |

R² = 0.061、モデル全体のF検定 p < 0.001。

![年齢と勝率の関係](hypothesis_age_quadratic.png)

**結論：「逆U字（中年期にピークがある）」という仮説の形そのものは支持されない。**
2次項（age²）の係数は統計的に有意（p=0.0023）だが、符号が **正**
（下に凸＝U字型）であり、想定していた「上に凸の逆U字（ピークが中間にある）」
とは逆の形になっている。

一方で、線形のみのモデルでは r = -0.237（p < 0.001）と、**本プロジェクトで
検証した全仮説の中で最も強い相関**が確認された。年齢層別の平均勝率は

| 年齢層 | 平均勝率 | n |
|--------|----------|---|
| 19〜22歳 | 80.9% | 20 |
| 23〜26歳 | 76.7% | 222 |
| 27〜30歳 | 73.1% | 573 |
| 31〜34歳 | 71.2% | 612 |
| 35〜38歳 | 69.3% | 333 |
| 39歳以上 | 68.4% | 99 |

と、20代から30代にかけて一貫して右肩下がりであり、40代でわずかに
 U字の底から持ち直すように見えるものの、その年齢層はn=99（さらに40歳以上
だけならn=64）と非常にサンプルが少なく、二次曲線が両端のわずかなデータに
引っ張られて持ち上がっている可能性が高い。つまり実質的には
**「年齢が上がるほど勝率は下がる」という単調減少の関係**が本データの
主たる発見であり、「ピークが中間にある」という当初の仮説は支持されなかった。

#### 考察

最も若い年齢層（19〜22歳）の勝率が最も高い（80.9%）点は意外に見えるが、
n=20と非常に小さく、デビューしてすぐに強さを示せた一部のプロスペクトのみが
目立って記録されている可能性がある（生存者バイアス）。一方、20代後半〜30代の
大半のサンプルでは年齢とともに勝率が安定して下がっており、これは加齢に伴う
反応速度・回復力の低下に加え、UFCでは連敗した選手が契約を切られて
データから消えていく一方、ベテランで「使われ続けている」選手は徐々に
強い相手と当たる回数が増える、といった構造的要因も影響していると考えられる。

再現するには:
```bash
python analyze_hypothesis_age.py --input ufc_analysis_data.csv --raw alt_fighters_stats.csv
```

### 仮説④の深掘り　― 年齢効果は「見せかけ」ではないか？

線形相関 r=-0.237 は全仮説中最も強いが、これが①特定の階級に偏った見せかけの
相関ではないか、②経験（試合数）との交絡で説明できてしまわないか、③具体的に
どの程度のインパクトなのか、という3点をさらに検証した
（`analyze_hypothesis_age_deepdive.py`）。

#### 1. 階級別の頑健性チェック

n≥30の9階級それぞれで年齢×勝率の相関を個別に算出。

| 階級 | n | 平均年齢 | r | p値 |
|------|---|----------|---|------|
| Flyweight | 191 | 29.8 | -0.357 | <0.001 |
| Lightweight | 313 | 31.0 | -0.281 | <0.001 |
| Bantamweight | 267 | 30.9 | -0.261 | <0.001 |
| Featherweight | 232 | 30.6 | -0.254 | <0.001 |
| Strawweight | 81 | 30.8 | -0.211 | 0.059 |
| Welterweight | 288 | 31.5 | -0.206 | <0.001 |
| Light Heavyweight | 154 | 32.8 | -0.205 | 0.011 |
| Heavyweight | 132 | 33.6 | -0.171 | 0.051 |
| Middleweight | 201 | 32.3 | -0.148 | 0.036 |

![階級別の頑健性](hypothesis_age_weightclass_robustness.png)

**9/9階級全てで負の相関、7/9階級でp<0.05の統計的有意性。** 特定の階級にだけ
現れる見せかけの相関ではなく、軽量級〜重量級まで一貫した構造的な傾向であることが
確認された。

#### 2. 交絡チェック（経験／試合数との混同ではないか）

年齢が高い選手は試合数（経験）も多い傾向がある（age × total_fights, r=0.456,
p<0.001）。そこで試合数を統制した**偏相関**（線形残差化による算出）を比較した。

| | 単純相関 r | 偏相関 r（試合数を統制） |
|---|---|---|
| 年齢 → 勝率 | -0.237 | -0.164 |

経験（試合数）を統制しても相関の約**69%**が残存。年齢には経験とは独立した
効果があると考えられる。

#### 3. 具体的な効果量

線形回帰の傾き（slope = -0.582）から、年齢が5歳上がるごとに勝率は約
**2.9ポイント**低下すると推定される。これを22歳（デビュー直後の典型年齢）と
35歳（ベテラン）で予測すると：

| 年齢 | 予測勝率 |
|------|----------|
| 22歳 | 77.5% |
| 35歳 | 70.0% |

**22歳→35歳で約7.6ポイントの勝率差**に相当し、年齢の影響は統計的有意性だけ
でなく、実務的にも無視できない大きさであることが分かる。

再現するには:
```bash
python analyze_hypothesis_age_deepdive.py
```
（`ufc_analysis_data.csv` と `alt_fighters_stats.csv` が同じディレクトリに必要）

## スクレイピングコードの使い方（ufc_scraper.py）

収集方法の実装として用意したコードです（実行可否はUFCStats.com側の
Bot対策状況に依存します）。

```bash
pip install requests beautifulsoup4 pandas

# 動作確認（a始まりの選手 50人）
python ufc_scraper.py --chars a --limit 50

# 全選手取得
python ufc_scraper.py
```

### 処理の流れ
```
Step 1: URLリスト収集
  └─ ufcstats.com/statistics/fighters?char=X&page=all
Step 2: 個別ページのスクレイピング
  └─ ufcstats.com/fighter-details/XXXXXXXX
Step 3: CSV保存
  └─ pandas で DataFrame に変換 → CSVに保存
```
